# Infaturamento

O Infaturamento é uma aplicação de organização financeira pessoal e familiar. Seu objetivo é facilitar o acompanhamento das entradas, dos gastos e do orçamento mensal em uma interface simples.

## Acesse

https://infaturamento-financeiro.vercel.app

## Funcionalidades

- Cadastro e acompanhamento de receitas e despesas.
- Resumo financeiro por mês.
- Gráficos de gastos por categoria.
- Definição de limites para o orçamento.
- Diagnóstico financeiro com sugestões de economia.
- Armazenamento dos registros no navegador.

## Tecnologias

React, TypeScript, Vite, Tailwind CSS e Google Gemini.
